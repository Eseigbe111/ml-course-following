# Machine Learning & NLP Portfolio

A collection of end-to-end machine learning, deep learning, and natural language processing (NLP) projects built using Python, Scikit-Learn, TensorFlow, Keras, and PyTorch. These implementations cover data preprocessing, feature engineering, predictive modeling, and model evaluation.

## Repository Structure

### 1. Natural Language Processing & Text Classification (`email-spam-identification/`)
* **Objective:** Classify unstructured text messages and identify near-duplicate documents efficiently.
* **Methods:** Text preprocessing, TF-IDF vectorization, batched sparse-matrix cosine similarity filtering, and supervised classification.
* **Key Focus:** Balancing Precision and Recall for reliable automated text screening and deduplication.

### 2. Multi-Class Image Classification (`dog-breed-identification/`)
* **Objective:** Categorize images across multiple breeds using deep learning.
* **Methods:** Convolutional Neural Networks (CNNs), transfer learning, tensor transformations, and data augmentation.

### 3. Vehicle Make & Model Classification (`Vehicle images dataset for the vehicle make and mo/`)
* **Objective:** Identify vehicle makes and models from multi-class automotive image datasets.
* **Methods:** Image preprocessing, feature extraction, deep learning classification pipelines, and validation accuracy/loss tracking.

### 4. Time-Series Regression (`bulldozer-price-prediction-project/`)
* **Objective:** Predict historical auction sale prices from large-scale structured, time-dependent tabular records.
* **Methods:** Tree-based ensemble regressors, exploratory data analysis (EDA), missing value imputation, and Root Mean Squared Log Error (RMSLE) optimization.

### 5. Clinical Binary Classification (`heart-disease-project/`)
* **Objective:** Predict diagnostic outcomes from structured clinical features, packaged with a lightweight Python application (`app.py`).
* **Methods:** Feature selection, hyperparameter tuning, and evaluation via Confusion Matrices, ROC curves, Precision, Recall, and F1-score.
